### 性能的两条实测结论（与静态推断不同，值得单独记住）

|---|---|---|
| SQLite 单写连接天花板 | ~300~400 req/s | **~6000~7000 req/s**，64 并发仅衰减 11%（WAL + `synchronous=NORMAL` 不 fsync） |

P0 是后者，但 `DefaultRetentionDays = 30` 硬编码（`usage_archive.go:35`）把它限制在 **~63ms**，除非剪枝失效。
